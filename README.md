# 智能语音视频识别提炼系统 (Intelligent Speech and Video Recognition and Extraction System)

音视频转写 · AI 会议纪要 · 视频内容摘要 · 关键词提取 · 声纹分析 · 多模态提炼 · 图表解析

本项目是一套面向会议、课堂、访谈、媒体内容等场景的智能语音视频识别与提炼平台，支持音视频转文字、AI 会议纪要生成、视频内容摘要、语音关键词提取、多模态信息提炼、声纹分析、语音内容图表解析等能力。系统通过语音识别、说话人分离、视觉理解、大模型摘要、知识图谱存储与多模态检索，将非结构化音视频转化为结构化纪要、摘要、关键词、时间轴、待办事项和可视化图表，适用于企业办公、教育培训、媒体内容分析、客户服务、执法记录、知识库建设等场景。

## 核心特性

- **高精度音视频转写**：支持实时录音与离线音视频文件转写，覆盖普通话、英语及多种方言，支持热词优化与口语书面化。
- **AI 会议纪要生成**：自动提炼会议主题、核心结论、关键决策、待办事项与责任人，支持章节速览、要点回顾、思维导图与自定义纪要模板。
- **视频内容摘要**：基于多模态大模型对视频画面、字幕、语音进行理解，生成时间轴摘要、章节划分、高光片段与关键事件描述。
- **语音关键词提取**：自动识别高频词、主题词、实体词、争议点与行动项，支持按发言人、时间段、话题维度聚合。
- **多模态信息提炼**：融合语音、文本、画面、PPT、图表、OCR 文字等多通道信息，实现跨模态对齐与结构化输出。
- **声纹分析与说话人识别**：支持说话人分离、声纹向量提取、身份关联、跨片段说话人追踪，可用于会议角色识别与执法场景人物关联。
- **语音内容图表解析**：通过画面帧采样、OCR、图表识别与 PPT 解析，将视频中的表格、流程图、板书、幻灯片内容转化为结构化数据。
- **知识图谱与多模态检索**：将转写文本、声纹、视觉标签、事件节点存入知识图谱，支持自然语言查询、跨片段检索与关联事件分析。
- **任务闭环与导出**：支持待办事项分发、纪要导出为 Word/Markdown/PDF/SRT，并可对接办公协作系统。

## 功能模块概览

### 音视频转写模块

- **实时录音转写**：支持会议、课堂、访谈场景下的实时语音转文字。
- **离线文件转写**：支持 MP3、WAV、MP4、M4A 等格式上传与批量转写。
- **多语言与方言识别**：支持中文、英语、日语、韩语及多种方言转写。
- **说话人分离**：自动识别不同发言人并标注发言段落。
- **热词优化**：支持导入人名、地名、专业术语，提高垂直场景识别准确率。

### AI 会议纪要模块

- **全文摘要**：自动提炼会议整体内容与核心观点。
- **章节速览**：按议题划分会议章节，支持快速定位。
- **要点回顾**：提取关键决策、风险点、争议焦点与结论。
- **待办提取**：识别行动项、责任人、截止时间，支持任务分发。
- **发言人总结**：按发言人汇总观点与任务。
- **思维导图生成**：将会议结构转化为可视化思维导图。
- **自定义模板**：支持企业自定义纪要格式与输出风格。

### 视频内容摘要模块

- **时间轴摘要**：按时间段生成视频关键内容概述。
- **章节划分**：自动识别视频段落、议题切换与场景变化。
- **高光片段提取**：识别重要发言、关键画面与高价值片段。
- **事件检测**：自动发现会议决议、异常事件、情绪变化与重点讨论。

### 关键词与主题提取模块

- **高频词提取**：统计音视频中出现频率较高的关键词。
- **主题聚类**：将内容按话题自动归类，如产品、需求、风险、进度等。
- **实体识别**：识别人名、机构名、时间、地点、项目名称等实体。
- **争议点标注**：标记讨论分歧、未决问题与需要跟进的事项。

### 多模态信息提炼模块

- **语音 + 文本融合**：结合转写文本与语音特征提升摘要准确性。
- **画面理解**：通过视觉模型识别 PPT、板书、人物、场景与物体。
- **OCR 文字提取**：解析视频截图中的文字、表格与幻灯片内容。
- **图文对齐**：将画面内容与对应语音段落进行时间轴对齐。
- **结构化知识库**：将音视频内容沉淀为可检索、可复用的知识资产。

### 声纹分析模块

- **说话人分离**：自动区分会议中的不同发言角色。
- **声纹向量提取**：为每个发言人生成声纹特征向量。
- **身份关联**：跨片段、跨会议识别同一说话人。
- **发言统计**：统计每位发言人的发言时长、发言次数与关键词。
- **声纹检索**：支持按说话人检索相关片段与纪要内容。

### 语音内容图表解析模块

- **表格还原**：从视频画面中识别表格结构并转换为结构化数据。
- **流程图解析**：识别流程图、架构图并生成文字说明。
- **板书提取**：从课堂或培训视频中提取板书内容与考点。
- **图表摘要**：对识别出的图表生成简要解读与数据总结。

### 知识图谱与检索模块

- **多模态图谱构建**：将说话人、事件、片段、关键词、图表节点存入图谱。
- **跨片段关联**：建立音视频片段之间的时间、人物、主题关联。
- **自然语言查询**：支持通过自然语言检索音视频中的关键内容。
- **事件时间线**：基于图谱边关系生成事件发展时间线。
- **关联分析报告**：输出人物关联、事件关联与关键发现摘要。

### 用户与任务管理模块

- **任务上传**：支持音视频文件上传、链接导入与批量处理。
- **任务进度跟踪**：实时展示转写、摘要、声纹分析、图表解析进度。
- **纪要编辑**：支持对 AI 生成纪要进行人工校对与二次编辑。
